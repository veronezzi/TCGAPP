# Pokemon Card Scanner - TCG Value Scanner

Aplicativo Android para escanear cartas Pokémon TCG e identificar preços de mercado, similar ao app Shiny.

## Funcionalidades

- **Scanner de Cartas**: Escaneia cartas Pokémon usando a câmera e OCR
- **Identificação de Preços**: Busca preços de mercado em tempo real
- **Coleção**: Gerencia sua coleção de cartas
- **Interface Moderna**: Dark theme com Material 3

## Tecnologias

- Kotlin
- Android Jetpack (CameraX, Room, Navigation)
- ML Kit (Text Recognition)
- Retrofit (API calls)
- Material 3

## Arquitetura

- Clean Architecture
- MVVM/MVI Pattern
- Repository Pattern
- Dependency Injection (Hilt)
